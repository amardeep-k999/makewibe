# Subscription Management System

A beginner-friendly Python project for managing subscriptions and recurring billing. The system is based on the Brightloop Software problem statement.

## Planned Features

- Manage products and subscription plans
- Track customers and their subscriptions
- Create invoices and record payments
- Support admin, staff, and customer access
- View basic subscription and payment summaries

## Technology

- Python
- The interface and specific tools or libraries are still to be decided.

## Project Status

Planning and initial setup. Features will be added step by step.
